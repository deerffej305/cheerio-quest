# Cheerio Quest

### Journey to the Center of the Anus

A 2D HTML5 platformer where **Crispy the Cheerio** survives the journey through the human digestive system. Six rooms, three bosses, two game modes, three leaderboards, one critically-timed fart.

Built as a learning-by-playing assessment for a 9th-grade biology class. Plays in any modern browser on Microsoft Surface tablets, laptops, and projectors.

## Run locally


```bash
npm install
npm run dev
```


Then open the URL Vite prints (typically `http://localhost:5173`).

## Tech stack

- [Phaser 3](https://phaser.io/) — HTML5 game framework
- [Vite](https://vitejs.dev/) — build tool and dev server
- Cloudflare Pages + Workers + KV — static hosting and leaderboard backend
